# Python鲜花商城系统简介

## 核心功能
- 登录注册
- 鲜花分类
- 浪漫花语
- 会员中心
- 购物车
- 下单
- 评论
- 用户管理
- 花语管理
- 鲜花管理
- 数据可视化总览
- 订单管理

## 适用场景
- 线上鲜花销售平台
- 用户购买鲜花
- 管理员维护鲜花信息及订单

## 技术特点
- 使用Django框架进行后端开发
- 数据库采用MySQL
- 前端使用Vue.js进行开发
- 支持远程调试和测试，确保系统稳定运行
